PATHPACK.GPU.apsp_gpu — Function
apsp_gpu(A; semiring = MinPlus(), devices = [CUDA.device()], output = :device)
apsp_gpu(A, sources; semiring = MinPlus(), output = :device)

The closure A* of the square sparse matrix A over semiring, on the GPU, in the vertex labels of A. Needs CUDA.jl (using CUDA).

source
PATHPACK.GPU.apsp_gpu! — Function
apsp_gpu!(H, A; semiring = MinPlus(), alg)
apsp_gpu!(H, plan, A)
apsp_gpu!(D, A; semiring = MinPlus(), alg)

The closure of A into the host matrix H, or into the device matrix D (a CuMatrix the caller allocated). Needs CUDA.jl.

source
PATHPACK.GPU.apsp_plan — Function
apsp_plan(A; semiring = MinPlus())

A plan for repeated closures of matrices with the pattern of A (new weights, same graph). Needs CUDA.jl.

source
