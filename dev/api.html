Library Reference ​

Everything you call is in two modules: PATHPACK.CPU (the solver and the semirings) and PATHPACK.GPU (the GPU solver, available once CUDA is loaded). Import what you use:

julia
using PATHPACK
using PATHPACK.CPU: MinPlus, MaxMin, mstar, mlu
using PATHPACK.GPU: apsp_gpu       # after `using CUDA`
You wantCall
every pair, on the CPUmstar(s, A)
some rows or columns, or many queriesmlu(s, A), then rmul!(B, F) (rows) or lmul!(F, B) (columns)
every pair, on one GPU or severalapsp_gpu(A; semiring, devices)
a few sources, on the GPUapsp_gpu(A, sources)
new weights on the same graph, on the GPUapsp_plan(A), then apsp_gpu(plan, A2)

Computing Stars ​

PATHPACK.CPU.mstar Function
julia
mstar(s::AbstractSemiring, A; alg = AMF(), nt = Threads.nthreads())

Compute the star A* = I ⊕ A ⊕ A² ⊕ ⋯ of the matrix A over the semiring s, as a dense matrix. A[i, j] is the weight of the arc i → j; A*[i, j] is the ⊕-sum over all paths from i to j of the ⊗-products of their arcs' weights. With MinPlus that is the shortest-path distance between every pair of vertices.

julia
D = mstar(MinPlus(), A)    # shortest paths
W = mstar(MaxMin(), A)     # widest paths

The result has n² entries; to compute only some rows or columns, factorize with mlu.

source
PATHPACK.CPU.mlu Function
julia
mlu(s::AbstractSemiring, A; alg = AMF(), nt = Threads.nthreads())

Factorize the star of the matrix A over the semiring s, A* = U* L*, for queries. A sparse A is ordered to reduce fill (alg: any elimination algorithm of CliqueTrees.jl, or a permutation) and factorized with the multifrontal method; a dense A is factorized directly. Then lmul!(F, B) gives A* B (columns of the star), rmul!(B, F) gives B A* (rows), and Matrix(F) the whole star. nt is the number of threads.

julia
F = mlu(MinPlus(), A)
B = fill(Inf, 1, size(A, 1)); B[1] = 0.0
rmul!(B, F)    # the distances from vertex 1
source
PATHPACK.CPU.pstar Function
julia
pstar(s::AbstractSemiring, A::SparseMatrixCSC; alg, nt)

The partial star of a sparse matrix: the entries of A* on the sparsity pattern of the factors, as a sparse matrix in the original vertex order.

source

lmul!(F, B) overwrites B with A* B, the least solution of X = A X ⊕ B; rmul!(B, F) overwrites B with B A*. Both take a matrix of right-hand sides at once and the keyword nt, and Matrix(F) is the whole star.

Semirings ​

PATHPACK.CPU.MinPlus Type
julia
MinPlus()

The tropical semiring ([-∞, ∞], min, +). With it, mstar(MinPlus(), A)[i, j] is the length of a shortest path from i to j; Inf means that j cannot be reached from i. Weights may be negative if no cycle is.

source
PATHPACK.CPU.MaxPlus Type
julia
MaxPlus()

The semiring ([-∞, ∞], max, +). With it, mstar(MaxPlus(), A)[i, j] is the length of a longest path from i to j: on graphs without positive cycles, for example the critical paths of a schedule.

source
PATHPACK.CPU.MaxMin Type
julia
MaxMin()

The widest-path semiring ([-∞, ∞], max, min). With capacities as weights, mstar(MaxMin(), A)[i, j] is the largest capacity of a single path from i to j.

source
PATHPACK.CPU.MinMax Type
julia
MinMax()

The bottleneck semiring ([-∞, ∞], min, max). With it, mstar(MinMax(), A)[i, j] is the smallest possible largest arc weight on a path from i to j: the mildest worst step.

source
PATHPACK.CPU.MaxProd Type
julia
MaxProd()

The Viterbi semiring ([0, ∞], max, ×). With probabilities in [0, 1] as weights, mstar(MaxProd(), A)[i, j] is the probability of the most reliable path from i to j.

source
PATHPACK.CPU.MinProd Type
julia
MinProd()

The semiring ([0, ∞], min, ×). With it, mstar(MinProd(), A)[i, j] is the smallest product of arc weights along a path from i to j.

source
PATHPACK.CPU.PlusProd Type
julia
PlusProd()

The semiring of nonnegative real numbers ([0, ∞], +, ×). With it, mstar(PlusProd(), B) is the sum over all walks, (I - B)⁻¹, for a nonnegative B whose spectral radius is below 1: diffusion, personalized PageRank, walk counts. Negative entries are outside this semiring.

source
PATHPACK.CPU.OrAnd Type
julia
OrAnd()

The Boolean lattice (2ⁿ, ∪, ∩) on sets of bits stored in integers. With labels as weights, mstar(OrAnd(), A)[i, j] is the set of labels that some path carries from i to j; with one bit, it is reachability. Use an integer type such as Int32.

source
PATHPACK.CPU.AndOr Type
julia
AndOr()

The Boolean lattice (2ⁿ, ∩, ∪) on sets of bits stored in integers: the dual of OrAnd.

source

GPUs ​

PATHPACK.GPU.apsp_gpu Function
julia
apsp_gpu(A; semiring = MinPlus(), devices = [CUDA.device()], output = :device)
apsp_gpu(A, sources; semiring = MinPlus(), output = :device)

The closure A* of the square sparse matrix A over semiring, on the GPU, in the vertex labels of A. Needs CUDA.jl (using CUDA).

source
PATHPACK.GPU.apsp_gpu! Function
julia
apsp_gpu!(H, A; semiring = MinPlus(), alg)
apsp_gpu!(H, plan, A)
apsp_gpu!(D, A; semiring = MinPlus(), alg)

The closure of A into the host matrix H, or into the device matrix D (a CuMatrix the caller allocated). Needs CUDA.jl.

source
PATHPACK.GPU.apsp_plan Function
julia
apsp_plan(A; semiring = MinPlus())

A plan for repeated closures of matrices with the pattern of A (new weights, same graph). Needs CUDA.jl.

source
PATHPACK.GPU.sssp_gpu! Function

Single-source solves on the GPU, one source per row of the output. Needs CUDA.jl.

source

julia
r, t = with_phases(f)

f() and the time of each phase of the GPU solver's calls in it (symbolic, numeric CPU / GPU part, transfer, inverse U_, solve L_, relabel, ...). Needs CUDA.jl.

source

source
