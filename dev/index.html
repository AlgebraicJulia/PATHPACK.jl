Julia · CPUs · NVIDIA GPUs

Every path,
between every pair.

PATHPACK.jl computes shortest paths, widest paths, reachability and their relatives between all pairs of vertices of a sparse graph, as one sparse factorization. One call, any semiring, on multithreaded CPUs and on one GPU or many.

Get started

Two lines.

using PATHPACK
using PATHPACK.CPU: MinPlus, MaxMin, mstar

D = mstar(MinPlus(), A)    # shortest paths between all pairs
W = mstar(MaxMin(), A)     # widest paths, same call

Any semiring

Shortest, widest, bottleneck, most reliable, reachability, sums over all walks: one solver.

Multithreaded CPUs

One sparse factorization, then independent rows: every core busy, no write conflicts.

One GPU or many

The CPU factorizes the small parts, the GPU the large ones; the rows split over every GPU you have.

Queries, fast

Factorize once, then answer single-source and single-target queries with two triangular solves.
