Factorize Once, Query Many Times ​

Download notebookThe same code as on this page, ready to run in Jupyter with IJulia.

mstar computes all entries of the star. Often only some of them are needed: the distances from a few depots, to a few hospitals, or from whichever node a user clicks next. PATHPACK.jl splits the work in two. mlu factorizes the star once,  ; then each query is a pair of triangular solves with the factors, which costs far less than the factorization.

A Directed Street Grid ​

A 60 × 60 grid of streets, 3,600 intersections. Going one way along a street can take longer than the other (a hill, a busy lane), so the graph is directed: distances from a place differ from distances to it.

julia
using PATHPACK, SparseArrays, Random
using PATHPACK.CPU: MinPlus, mstar, mlu
using LinearAlgebra: lmul!, rmul!

Random.seed!(2)
k = 60; n = k * k
id(i, j) = (j - 1) * k + i
src = Int[]; dst = Int[]; minutes = Float64[]
for j in 1:k, i in 1:k, (a, b) in ((1, 0), (0, 1))
    (i + a <= k && j + b <= k) || continue
    u, v = id(i, j), id(i + a, j + b)
    push!(src, u, v); push!(dst, v, u); push!(minutes, rand(1:5), rand(1:5))
end
A = sparse(src, dst, minutes, n, n);

The Factorization ​

mlu takes the same arguments as mstar and returns the factorization instead of the star.

julia
F = mlu(MinPlus(), A);

For checking the queries below, here is the whole star too:

julia
D = mstar(MinPlus(), A);

Distances From Some Sources: Rows ​

rmul!(B, F) overwrites B with . Give B one row per source, holding the semiring's one (0) at the source and its zero (Inf) everywhere else, and each row becomes that source's distances to every node.

julia
sources = [id(1, 1), id(30, 30), id(60, 1)]
B = fill(Inf, length(sources), n)
for (r, s) in enumerate(sources)
    B[r, s] = 0.0
end
rmul!(B, F)
B == D[sources, :]
true

Distances To Some Targets: Columns ​

lmul!(F, X) overwrites X with . With one column per target, each column becomes the distances from every node to that target.

julia
targets = [id(60, 60), id(15, 45)]
X = fill(Inf, n, length(targets))
for (c, t) in enumerate(targets)
    X[t, c] = 0.0
end
lmul!(F, X)
X == D[:, targets]
true

Rows and columns differ here, since the graph is directed:

julia
D[id(1, 1), id(60, 60)], D[id(60, 60), id(1, 1)]
(213.0, 209.0)

Many Queries ​

The factorization is reused across calls. Timing on this small grid, on the threads this page was built with (after a first call of each, so that compilation is not counted):

julia
function rows(S)
    B = fill(Inf, length(S), n)
    for (r, s) in enumerate(S)
        B[r, s] = 0.0
    end
    return rmul!(B, F)
end
rows(1:1); rows(1:100); mlu(MinPlus(), A); mstar(MinPlus(), A);

t_factor = @elapsed mlu(MinPlus(), A)
t_single = @elapsed for s in 1:100
    rows(s:s)
end
t_block = @elapsed rows(1:100)
t_star = @elapsed mstar(MinPlus(), A)
ms(t) = round(1000t; digits = 2)
(factorization = ms(t_factor), one_row = ms(t_single / 100),
    hundred_rows_one_call = ms(t_block), whole_star = ms(t_star))
(factorization = 4.27, one_row = 0.95, hundred_rows_one_call = 3.73, whole_star = 38.18)

The times are in milliseconds, measured on the machine that built this page, so they vary from build to build. The factorization is paid once; each row afterwards costs a small fraction of it, and many rows in one call share the work of the solve.

New Weights, Same Graph ​

When the weights change but the streets do not (travel times at another hour), the ordering and the symbolic analysis of the graph can be kept. ChordalSLU holds them; copyto! loads new weights and lu! factorizes.

julia
using PATHPACK.CPU: ChordalSLU
using LinearAlgebra: lu!

G = ChordalSLU(MinPlus(), A)            # the symbolic part, once
rush = copy(A); nonzeros(rush) .*= 2    # every street twice as slow
copyto!(G, rush); lu!(G)
B = fill(Inf, 1, n); B[1, id(1, 1)] = 0.0
rmul!(B, G) == 2 .* D[id(1, 1):id(1, 1), :]
true

Threads ​

Every one of these functions takes the keyword nt, the number of threads, and uses all of Julia's threads by default. For example, mlu(MinPlus(), A; nt = 4) or rmul!(B, F; nt = 1). Start Julia with --threads auto to use every core.
